Project Documentation & Report

1. Overview & Time Spent

Creating this website was a learning experience that helped me move from initial ideas in wireframes to a working responsive web application! :) The whole project took me about 25 to 30 hours. I spent my time planning making prototypes in Figma building the HTML adding styles with CSS and testing how to layout looks on screen sizes.

2. Problem Solving & Challenges

What was hard? Well, the whole project was so hard for me because I don´t have any coding background, I need to investigate about everything. I watch so many videos and our lectures again and again and I guess I can do a lot of things now! :) The biggest challenge for me was keeping the layout consistent on devices. I had to work a lot with Flexbox and Grid to make sure elements didn´t overlap. It took a lot of trying and fixing.

What was simple and fun? Putting together the HTML structure was super easy. The fun part was writing custom CSS and watching the designs I made in Figma show up exactly as I wanted on the browser.

3. Key Learnings & Course Reflection

During this course I learned a lot about front-end practices. I worked with HTML5 organized CSS planned design components.

Course Feedback: I really liked the way the course was structured. Working on a project helped me understand the ideas better. For the time adding a short lesson on advanced CSS animations would be a great idea!

4. Design

I worked hard to make the layout simple and easy to use. I choose a color scheme and made sure the text was easy to read. Things I want to point out for attention include using proper HTML5 tags for structure and accessibility making sure the layout works well on the all devices without using big outside CSS tools and keeping the code neat and organized.

5. Conclusion

The lectures and the project was quite fun! It helped me get better at building web pages from the ground up. Made me more confident, in my front-end skills.
